# 講義用リアルタイムクイズ＆感想共有Webアプリ — 要件定義

## 概要

大学や高校の講義で使用する、参加者がリアルタイムでクイズに回答したりフリーテキストで感想を共有できるシンプルなWebアプリケーション。Node.js + Socket.IO によるサーバーを用いて、複数端末間でリアルタイム同期を行う。

## 技術要件

- 開発言語: JavaScript（サーバー・クライアント共に）
- サーバー: Node.js + Express + Socket.IO
- クライアント: HTML / CSS / JavaScript（フレームワークなし）
- 構成: `server.js`（サーバー）+ `public/index.html`（クライアント）
- Socket.IO クライアントライブラリはサーバーから自動配信（CDN不要）
- 外部フロントエンドライブラリ依存なし

## 機能要件

### FR-1: 参加者の識別（匿名・あだ名）

- 参加者はアプリ起動時に「ニックネーム」を任意で入力する
- 未入力の場合は「匿名ユーザー」として自動割当される
- 本名やメールアドレスなど個人情報の収集は行わない

### FR-2: クイズ機能（出題者モード）

- 出題者（講師）はクイズの問題文を入力できる
- 選択肢を2〜4択で設定できる（デフォルトは3択）
- 正解の選択肢を指定できる
- 「出題開始」ボタンでクイズを全参加者にリアルタイム配信する
- 回答状況をリアルタイムで集計・棒グラフ表示する
- 「結果発表」ボタンで正解と集計結果を全員にリアルタイム共有する

### FR-3: クイズ機能（回答者モード）

- 出題されたクイズがリアルタイムで画面に表示される
- 参加者は表示された選択肢から1つを選んで回答する
- 回答後は変更不可とする
- 結果発表時に正解・不正解のフィードバックをリアルタイムで受け取る

### FR-4: フリーテキスト感想共有

- 参加者はフリーテキストで感想やコメントを投稿できる
- 投稿された感想はリアルタイムで全参加者に表示される
- ニックネーム付きで表示される

### FR-5: 画面モード切替

- 「出題者モード」と「参加者モード」を切り替えられる
- 出題者モードではクイズ作成・管理が可能
- 参加者モードではクイズ回答・感想投稿が可能

### FR-6: リアルタイム同期

- WebSocket（Socket.IO）によりサーバー経由で全端末間のデータをリアルタイム同期
- クイズの出題・回答・結果発表・感想投稿がすべてリアルタイムに反映される
- 参加者数の表示

## 非機能要件

### NFR-1: シンプルなGUI

- モバイル・PC両対応のレスポンシブデザイン
- 直感的に操作できるシンプルなUI
- 講義中に大画面プロジェクターで表示しても見やすいレイアウト

### NFR-2: 個人情報保護

- 個人を特定できる情報は一切収集しない
- データはサーバーメモリ上にのみ存在し、永続化（DB保存）しない
- サーバー再起動でデータはクリアされる

### NFR-3: 簡単な起動

- `npm start` コマンド1つでサーバーが起動する
- 参加者はブラウザで指定URLにアクセスするだけで利用可能

## 利用フロー

1. 講師が `npm start` でサーバーを起動
2. 講師がブラウザでアクセスし「出題者モード」を選択
3. 参加者が各自のスマホ/PCからアクセスし「参加者モード」を選択
4. 講師がクイズを作成・出題 → 全参加者の画面にリアルタイム表示
5. 参加者が回答 → 講師の画面にリアルタイムで集計反映
6. 講師が結果発表 → 全員に正解と集計結果が表示
7. 参加者が感想を投稿 → 全員の画面にリアルタイム反映

## 画面構成

1. **エントリー画面**: ニックネーム入力 + モード選択（出題者/参加者）
2. **出題者画面**: クイズ作成フォーム + リアルタイム集計表示 + 感想一覧
3. **参加者画面**: クイズ回答 + 感想投稿 + 結果閲覧
